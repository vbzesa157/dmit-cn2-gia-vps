## CN2 GIA 贵在哪，这笔钱买的是什么

中国电信的骨干网分几档。最常见的是 AS4134（ChinaNet，也叫 163 网），容量大、价格低，晚高峰丢包率能到 30% 以上。往上是 CN2（AS4809），其中 CN2 GT 在 2019 年之后也开始拥堵；再往上是 CN2 GIA，回国流量走 59.43 节点，独立链路、负载轻，是目前电信线路里最稳的一档。

价差也在这几档之间拉得最开。业内流传的商家口径是 CN2 GIA 的 IP transit 最高卖到 $120/Mbps，一条 1Gbps 线路满带宽跑一个月，账单能到 $100,000 级别。这个数字是商家转述而非电信官方报价，但足以解释为什么 CN2 GIA 套餐普遍按小包装卖：给你 1TB 流量和 1Gbps 端口，而不是一根独享千兆。

实际体感上，洛杉矶 CN2 GIA 到国内电信的延迟大致在 130–200ms 之间，随机房和时段波动。它比普通线路好看的地方不在最低值，而在晚八点到十一点那一段。

CN2 GIA 有个绕不开的限制：容量稀缺，遇到大流量 DDoS 只能 nullroute，扛不住攻击。拿它跑对可用性有硬要求的业务，这条得提前想好。

## Pro、EB、T1：三条线路的实际区别

## 超额、退款、换 IP：条款里的四件事

**退款分三档。** 新购 3 天内、已用流量不超过 30GB，可以全额退，扣除支付网关收取的交易手续费。新购 30 天内按剩余流量和剩余时长核算，部分退。以下情形不予退款：续费订单、余额支付的订单、滥用、以网络或 IP 地区问题为由、同一系列产品已退款 3 次，以及流量已超 3GB 的「部分地区 IP 不可用」。IP 不可用的情况需要在购买当天联系客服。

**换 IP 按系列分权限。** Pro 和 EB 在满足四个条件时可以免费换：实例已购满 7 天、距上次换 IP 满 15 天、ICMP 和所有 TCP 端口都被屏蔽、剩余服务时长不少于 7 天。付费换 IP 是 $5 一次，条件是已购满 24 小时、距上次换 IP 满 24 小时、剩余时长不少于 24 小时。T1 没有免费额度，只能付费换，且距上次换 IP 要满 3 天。IP 由系统随机分配，不能指定地区或网段，换完不可撤销、不退款。

这条对国内用户的实际意义在于，IP 被墙时 Pro/EB 有一条免费通道，T1 只能每次掏 $5。买 T1 省下的钱，可能在第一次换 IP 时就还回去一部分。

**流量可以重置。** 每次重置恢复基础流量的 20%，截至产品有效期前最多免费重置 2 次，活动到 2026 年 12 月 31 日结束。额度直接下发到账户，在产品控制面板点「流量重置」按钮即可。这个额度对 TINY 这种小流量档比较实用，等于白送 400GB。

**开通和登录方式。** 注册只需要邮箱和密码，不需要上传证件。系统默认使用 SSH 密钥登录而不是用户名密码，第一次连接前要先把公钥配好，官方提供中文教程。支付支持支付宝、PayPal、信用卡、加密货币和银行转账。

条款会随版本调整，下单前在官网的服务条款页对一遍，尤其是退款和换 IP 这两部分。
